排班規則：只在開始日與結束日（含）之間的上課日排班。週六、週日及假日管理中設定的休假日會跳過；職稱非「學員」的幹部（班長、副班長、服務股長）不列入值日生輪替，系統會自動跳過。學員依學號排序，每日安排 1 或 2 位值日生並循環，直到結束日。若要將週末設為上課日，請在「假日管理」勾選該日為上課日。

資料備份提醒

本系統資料儲存在目前瀏覽器的本機儲存空間。若改用其他瀏覽器、清除瀏覽資料或換電腦，資料不會自動同步。請定期至「匯入／匯出」匯出完整 JSON 備份。

假日與上課日管理

系統預設排除週六、週日；這裡可新增國定假日、停課日，或將週末指定為上課日。離線版本不會自動連線更新政府公告，請依每年度正式行事曆維護假日。

自動更新國定假日

透過台灣行事曆公開 API（資料來源：政府行政機關辦公日曆表）自動匯入國定假日與週末補班日。已有手動新增的假日一律保留，同一日期以手動設定優先，就算 API 停用也不影響手動維護。

注意：API 有每秒 2 次請求的限制，請勿頻繁點擊。由於中華民國政府行政機關辦公日曆表更新日期約為每年6月底更新下一年度的行事曆，因此此自動更新也會於每年6 月底更新下一年度的行事曆。
